## ワークパッケージ

### WP1: 予測子スタック（他の全WPの前提）

**入力**: `ortho/data/snow/raw/*.tiff`（10年）、`ortho/data/terrain_features/*.tif`、
`ortho/data/vege_{2012,2021}_5x5.tiff`

**処理**:
1. 融雪10年気候値 `snow_mean` を**素の `as_tibble()`**（または terra 完結）で構築。
   半ピクセルずれを再導入しないこと（`add_max=TRUE` 禁止）
2. 画素ごとOLSトレンド面と、シナリオ用のシフト量定数（0 / −0.71 / −2.24 d/yr）
3. aspect → northness = cos(aspect·π/180), eastness = sin(aspect·π/180)
4. スタック: slope, elevation, TPI, twi, northness, eastness, snow_mean
   （roughness・TRI は入れない）
5. 全レイヤを vege グリッド（EPSG:6690, origin (0, 0.25), 1801×1753）に厳密整合

**受け入れチェック**:
- 全レイヤの `ext()`・`res()`・origin が vege_2012_5x5.tiff とビット一致
- `snow_mean` の平均が既知値 170.4257 ± 0.01（DOY>0 規則、全年有効画素）
- VIF < 5（全予測子）、|r| < 0.7（Spearman）

### WP2: モデルA（環境ポテンシャル）

**処理**: 2021年在 / 疑似不在（5 mセル間引き）、tidysdm、spatial_block_cv(v=4)、
tune_grid(grid=18)、stacks ブレンド。標高カットオフは
**「なし」を主、「<2560 m」を感度**として両方実行（未解決判断5の指示どおり）。

**出力**: 連続適性ラスタ、CV held-out max-TSS 閾値、応答曲線（DALEX PDP）、
最終アンサンブル構成表、閾値感度曲線（0.1〜0.7）

**受け入れチェック**:
- held-out TSS が旧TBM（0.556）から大きく劣化していない（−0.05 以内なら許容、
  劣化したらそのまま報告）
- 応答曲線が snow_mean について生態学的に読める形か（レビューで判断）

### WP3: モデルB（定着GAM）

**処理**:
- 応答: 2012年に非ササ（class≠1）→ 2021年にササ(=1) の二値。
  標本域は 2012年非ササ全域（class 2 に限定しない。定着先の98%は class 2 だが
  裸地等も含める）
- 予測子: WP1スタック＋ `dist12`（2012年ササ、**5 m²超ポリゴン基準**、
  decisions.md ②のとおり全解析で統一）
- mgcv::gam, binomial, s(dist12) + s(snow_mean) + s(elevation) + …
  （平滑の仕様は Codex 提案 → Claude レビューで確定）
- 空間ブロックCV（モデルAと**同一のブロック分割**を共有すること）
- 頑健性: 同じ応答・予測子で tidysdm アンサンブル版も学習し AUC を並記

**受け入れチェック**:
- held-out AUC が `sdm_sasainc.R` 系の既知値（env+dist ≈ 0.87）と整合
- s(dist12) が単調減少に近い形（分散カーネルとして解釈可能）
- ブロック間のAUCばらつきを報告

### WP4: セルオートマトン（投影）

**処理**:
- 初期状態 = 2021年ササ分布。年ステップ 2021→2030（9回）
- 各年: 現分布から距離面を再計算 → シナリオの融雪シフトを適用 →
  各非ササセルの p₉ を GAM で評価 → p₁ = 1−(1−p₉)^(1/9) → Bernoulli 抽選
- 反復 ≥100回 × シナリオ3水準
- **ヒンドキャスト**: 2012年初期値で同一機構を9年回し、2021年観測と比較
  （純増面積・前線移動距離・定着セルのヒット率）。較正チェックである旨を出力に明記
- **空間独立検証**: ブロック伏せ学習の GAM で伏せブロック内の定着を予測

**受け入れチェック**:
- ヒンドキャストの期待純増が観測（+1,629 m²…gross gain 4,097 m²）の±50%以内。
  外れた場合は外れたまま報告（隠さない）
- 距離面の年次更新が実際に効いていること（更新なし版との差分を1枚出す)
- 実行時間: 12コアで一晩以内（反復は並列化）
