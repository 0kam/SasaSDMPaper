## 1. 共通スタイル仕様（全図に適用）

- **テーマ**: スキル付属 `figure-recipes.R` の `theme_paper(base_size = 8)` を1箇所で定義し全図で使用。
  図中タイトルは全廃（キャプションへ）。パネルラベルは小文字 a, b, c（patchwork `tag_levels = "a"`）
- **寸法**: 90 / 140 / 190 mm のいずれかを各図で明示。`ggsave(units = "mm")`。
  仕上がり文字 ≥7 pt（軸目盛含む）。geom_text は `size.unit = "pt"`
- **地図の描画範囲**: 全域表示をやめ、**ササ関連図は共通のコア範囲**
  （E 732850–733750, N 4050850–4051550 目安、1:1アスペクト）に統一。
  全域が必要な図のみ全域＋コア範囲の枠線表示。等高線は `grey80`・0.2 mm・100 m間隔に減量
- **配色**: 連続=viridis系またはscico batlow、差分（0が意味を持つ）=scico vik、
  カテゴリ=Okabe-Ito。確率マップの現行 OrRd 系は viridis::rocket（逆順）等に置換可否を実装時に比較。
  グレースケール化・deutan で検証
- **2021年ササ分布の重畳表現を全図で統一**: 黒塗り潰しに見える現行輪郭をやめ、
  細線（0.3 mm）＋ラベル「2021 *Sasa*」で統一。図間で同じ表現
- **用語（軸・凡例ラベル英語辞書）**: snow_mean → "Mean snowmelt date (DOY)" / elevation →
  "Elevation (m)" / slope → "Slope (°)" / TPI → "Topographic position index" / twi →
  "Topographic wetness index" / northness → "Northness (cos aspect)" / eastness →
  "Eastness (sin aspect)"。invasion は使わない（expansion / encroachment）。
  suitability は "habitat suitability"（probability とは呼ばない）
- **出力**: ベクター `cairo_pdf`、ラスタ大量の地図は `ragg::agg_tiff(res = 500–1000,
  compression = "lzw")`。**1図=1スクリプト**（`analysis/figures/fig01_*.R` … 新設ディレクトリ）、
  乱数 `set.seed`、キャプション第1文は結論文
- 投稿は英語図のみ作成し、日本語確認版も同じ図を参照する（図8の群集名は学名表記で解決）

## 2. 図セットの再構成（本文6図案）

Reviewer 3の「図数削減」に沿い、現行8図 → **本文6図＋SI**。
図だけでストーリー: ①枠組み → ②何がどう変わったか → ③環境の窓 → ④【key】適地は広いが定着は前線 → ⑤将来も前線近傍・融雪感度は限定的 → ⑥危ないのは2つの雪田群落。

### Fig. 1（新規作成）: ワークフロー＋モデル概念図 — 190 mm、4パネル
- **メッセージ**: 「1台のカメラから植生図と融雪図を作り、2つの拡大様式に対応する2モデルで拡大を投影する」
- (a) データ生成: カメラ写真1枚 → 位置合わせ → 植生図2012/2021・融雪DOY 2011–2021（サムネイル+矢印）
- (b) モデルA: 2021年在＋環境 → 適性面。ラベル "Where the environment permits (seed layer)"
- (c) モデルB: 模式格子で2012年パッチ・距離バンド・2021年定着セル → "Where the front reaches (rhizome layer)"
- (d) セルオートマトン: 年ループ（距離面更新 → p₉→p₁ → Bernoulli → 占有更新）、融雪シナリオ s の入力位置
- 作成手段は R に固定しない（Inkscape/SVG可）。ただしソースファイルをリポジトリに置く
- 旧図1は廃棄。**HSMボックス追加という Reviewer 3 要求は (b) が満たす**

### Fig. 2（旧図2+図3を統合再設計）: 調査地とササの9年変化 — 190 mm
