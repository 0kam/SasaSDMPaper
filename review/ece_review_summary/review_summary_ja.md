## 2. 論点A: 「48%増加」の報告が誤解を招く

**指摘者: Reviewer 1（Major #3）、Reviewer 2（Major #1）— 2名が独立に指摘。最優先。**

### 指摘内容

Sasa分布面積は 8,542 → 10,170 m²、すなわち**純増 1,628 m²（19%）**。論文が繰り返す「48%」は、損失 2,467 m² を差し引く前の**gross expansion（粗拡大量）**である。gross expansion / gross loss / net change の区別を、**Abstract・Results・図・Discussion・Conclusion のすべてで**維持せよ。現在の記述は増加量を過大に見せている。

さらにReviewer 1は、「見かけの損失は低木がSasaを覆い隠したため」という説明が**仮定にとどまり実証されていない**として、以下を要求している。

- 2012年のどの植生クラスが2021年にSasaを置き換えたかを示す**遷移行列**
- 該当する低木カテゴリの特定（ナナカマド／カエデ／ミヤマハンノキ／広義の "Other Vegetation" のいずれか）
- 樹冠下でSasaが存続していたかを示す野外観察または追加の画像判読
- 最低限、**net と gross の両方を提示**し、遮蔽による見かけの損失割合を変えた**感度分析**を行うこと

### 対応策

**遷移行列は算出済み**（`ortho/data/vege_{2012,2021}_5x5.tiff` から直接計算）。

```
遷移行列  行=2012 列=2021  (単位: m², 1 m ピクセル)
          1        2        3        4        5        6        7    合計
  1     6079      932        3      159       85      133     1156    8547
  2     2171   432237    32001     3033      380     7187     9385  486402
  3       13     5096   342186       49        0       16    10569  357937
  4      224     3738       30    17284      871     2682     2104   26934
  5      155      624        0     1271     2523      703      424    5700
  6      109     3647       45     2023      234    13033     1683   20774
  7     1425     5491     6418     1370      209     1189   278651  294760
```

| 指標 | 値 |
|---|---|
| Sasa 2012 | 8,547 m² |
| Sasa 2021 | 10,176 m² |
| gross expansion | **4,097 m²（2012年比 47.9%）** ← 論文の「48%」 |
| gross loss | **2,468 m²（28.9%）** |
| net change | **+1,629 m²（+19.1%）** |

対応の骨子:

1. **本文の記述を三段構えに書き換える。** 「2012年から2021年にかけて、4,097 m²（2012年面積の47.9%）が新たにSasaに転換し、2,468 m²（28.9%）がSasa以外に転換した。結果として純増は1,629 m²（19.1%）であった」。Abstractもこの形式にする。
2. **遷移行列を新規Table（またはSupporting Information）として追加。**
3. **クラス1↔7の対称的交換を正面から論じる。** 1→7 が1,156 m²、7→1 が1,425 m² と、**損失の47%・獲得の35%がこの1ペアに集中し、ほぼ相殺している**。これは実際の植生変化というより**両クラス間の分類誤り**である可能性が高い。これを「変化検出の不確実性」として明示的に扱えば、Reviewer 1が求める感度分析の中核になり、同時に「損失＝遮蔽」という単純な説明への依存を減らせる。
4. **感度分析**: 見かけの損失のうち遮蔽由来とみなす割合を 0%・50%・100% と振り、net change の幅を示す。クラス1↔7の交換を分類誤差として除外した場合の net も併記する。

### 要確認事項（着手前に解決すること）

**植生クラス番号の対応が不明確。** `run_rnn.py` のカラーマップでは 1=Sasa, 2=Other vegetation, 3=No vegetation, 4=ナナカマド, 5=ダケカンバ, 6=(不明), 7=ハイマツ と読める。しかし `scripts/sdm/sdm_tdm.R:279` は `layer == 6` に `is_others` という変数名を与え、`risky_area` は `vege21 == 2` で絞っている。0始まり／1始まりのオフセット混入が疑われる。**遷移行列を論文に載せる前に、実データとラベルJSONを突き合わせて確定させる必要がある。**

**論文の数値とラスタ実測値が5〜6 m²ずれている**（論文 8,542 / 10,170 / 2,467 に対し実測 8,547 / 10,176 / 2,468）。NA処理か 5 m² ポリゴンフィルタの適用有無に由来すると思われる。査読者が電卓を叩いている以上、どの定義の値を報告するのかを確定し、Methodsに明記すること。

## 3. 論点B: 因果の主張が強すぎる

**指摘者: Reviewer 1（Major #4）、Reviewer 2（Major、Discussion改稿案）、Reviewer 3（総評・L328）— 3名全員。**

### 指摘内容

- **Reviewer 1**: 論文は繰り返し「早期融雪がSasa拡大を facilitated / drove した」と結論している。しかし融雪時期は空間構造をもつ複数の予測変数の1つにすぎず、植生分布の比較はわずか2時点である。**permutation importance は予測性能への寄与を示すだけで、因果メカニズムを立証しない**。追加解析を提示するか、全文の表現を「association（関連）」に改めよ。**Response curve / partial dependence plot** を示して、推定された融雪応答の方向と形状を明らかにすべき。
- **Reviewer 2**: 融雪時期は地温・土壌水分・凍結融解履歴・露出度・地形的位置と共変する。土壌温度・水分の実測と動的定着モデルがなければ、融雪時期の影響を相関する環境要因から分離できない。
- **Reviewer 3**: 他の予測変数がすべて地形由来であり積雪と強く相関する以上、DOYの高い説明力は当然であって意義は限定的。生物的要因・気候・その他の独立変数が無視されている。「本研究は融雪日を定量しただけである」（L328への指摘）。

### 対応策

**追加の野外データは取得できない以上、「表現を改める＋できる解析を出す」の二本立てで応じる。**

1. **全文の因果表現を機械的に洗い出して置換する。** `drove` `facilitated` `caused` `driven by` `responsible for` を検索し、`was associated with` `was among the strongest correlates of` `is consistent with` に置換。タイトルの "Snowmelt-driven" も再考の対象になる（ただしタイトル変更は編集部と要相談。少なくとも本文・Abstractの主張は下げる）。
2. **Response curve / PDP を新規図として追加**（`model_stack.rds` から算出可能、再学習不要）。融雪DOYに対する応答の形状を示すことは、Reviewer 1の直接要求への回答であると同時に、生態学的解釈を強化する。
3. **共線性の定量化**（→ 論点C）をもって、「DOYの重要度は他の地形変数と分離できない」という査読者の懸念に**数値で応答する**。隠すのではなく、限界として明示的に定量する方が説得力がある。
4. **考察に「代替説明」の段落を新設。** Reviewer 2が提案した改稿案（融雪時期は地温・土壌水分・凍結融解履歴・露出・地形位置と共変する／土壌の実測と動的定着モデルが必要）は、そのまま採用してよい内容。ただし査読者が併記した引用文献の扱いは §16 参照。
5. **限界と今後の課題**として、土壌温度・水分の実測、3時点以上の植生図、動的定着モデルの必要性を明記する。

## 4. 論点C: 予測変数の共線性が未評価

**指摘者: Reviewer 2（Major）、Reviewer 3（総評）**

### 指摘内容

標高・傾斜・roughness・TRI・TPI・傾斜方位・融雪時期は、相関した空間情報を含んでいる可能性が高い。**強い予測変数間相関のもとでは、permutation importance は関連変数のあいだで重要度を分割・再配分してしまい、生態学的ドライバーを信頼性をもって同定できない。**

要求:
- **相関行列とVIF（分散拡大係数）の提示**
- **冗長な地形変数の除去または統合**

### 対応策

1. **相関行列（Spearman）とVIFを算出**し、Supporting Information に掲載。`ortho/data/terrain_features/*.tif` 7層＋融雪ラスタから直接計算できる。R の `car::vif` または相関ベースの逐次除去。
2. **冗長変数の削減**: roughness・TRI・TPI は定義上ほぼ同族（いずれも近傍標高差の要約統計量）であり、相関が高いことがほぼ確実。**VIF > 10 を目安に削減した縮約変数セットで再学習し、変数重要度の順位が保たれるかを確認する**。順位が保たれれば「共線性があっても結論は頑健」と主張できる。変われば、その事実を正直に報告し主張をさらに下げる。
3. これは**再学習を伴う唯一の必須作業**。12コアで数時間〜半日を見込む（元は18スレッド前提のコード。§17参照）。
4. 縮約前後の変数重要度図を並置し、「頑健性チェック」としてSupporting Informationに置く。

> **判断**: Reviewer 3の「地形変数と積雪が相関するのでDOYの説明力は当然」という批判に対しては、共線性を定量したうえで**「DOYは地形変数の線形結合では説明しきれない独立の情報を持つ／持たない」を数値で示す**のが最も強い応答になる。ここは逃げずにやるべき。

## 5. 論点D: 融雪トレンドの統計的裏付けが不足

**指摘者: Reviewer 2（Major #3）**

### 指摘内容

「10年あたり平均8.6日の前進」は論文の中核だが統計的裏付けが不十分。2011〜2021年という比較的短い期間、大きな年々変動、そして**2019年の観測欠測**がある。

要求:
- ピクセル単位の傾きの**平均・中央値・標準偏差・信頼区間**
- **傾きが負／正のピクセルの割合**
- 全体トレンドの**統計的有意性または不確実性**

### 対応策

**指摘は事実。** `ortho/data/snow/raw/` を確認したところ、実データは **2011–2018, 2020, 2021 の10年分**で、2019年は存在しない。2010年は `data/snow/aligned/` にPNGがあるがGeoTIFF化されていない。

1. **2019年欠測とデータ年数（10年）をMethodsに明記する。** 現在は「2011–2021」と書かれており、11年分あるかのように読める。欠測理由（撮影失敗／画像品質など）も1文で述べる。2010年PNGが使える状態なら、ジオリファレンスして11年に増やす選択肢もある（トレンド推定の安定性が上がる）。
2. **ピクセル単位回帰の要約統計を全面的に提示。** 平均・中央値・SD・95%信頼区間、負／正の傾きのピクセル割合、有意ピクセルの割合。これは `preprocess_snow_data.R` の枠組みで計算できる。
3. **既存コードに要注意箇所がある。** `preprocess_snow_data.R:130` は `filter(lm.r2 > 0.2)` で決定係数の低いピクセルを除外している。この閾値の根拠と、除外されたピクセルの割合を報告しないと、「トレンドが見えるピクセルだけ選んだ」という選択バイアスの批判を招く。**全ピクセルの傾き分布を報告し、フィルタは感度分析として扱う**のが安全。
4. **年平均DOYの時系列と回帰を図示**（信頼帯つき）。年々変動の大きさが一目でわかる図があれば、「短期間・高変動」という批判に対して誠実な応答になる。
5. 「8.6日/10年」を報告する際は**必ず不確実性を併記**し、外挿（2030年予測）が**予測ではなくシナリオ**であることを明示する（→ 論点E）。

## 6. 論点E: 2030年予測の設計・閾値・不確実性

**指摘者: Reviewer 1（Major #5）、Reviewer 2（Major）**

### 指摘内容

**(a) distance変数の構成が不明**（2名が指摘）
Methodsは「2012年分布からの距離をTDMに含めた」と書いているが、2030年投影で距離をどう表現したかが説明されていない。**公開コードは2021年分布から将来距離レイヤを計算しているように見える。** 動的更新自体は妥当だが、Methodsに明示しワークフロー図にも反映せよ。2030年投影が「観測された2021年縁辺からの継続的拡大」を仮定するのか、「予測された2021年セル全体への無制限の定着」を仮定するのかを説明せよ。

**(b) 閾値0.5の根拠**
生息適地・「risky」域の判定に用いた 0.5 は、生態学的にキャリブレーションされた閾値なのか、単なる確率の既定値なのか。**代替閾値への感度**を報告せよ。

**(c) 不確実性の非表示**
予測の不確実性を示すべき。とくに **TBMのtest TSSが0.55** と低く、観測された2021年分布を**大幅に過大予測**している。

**(d) シナリオであることの明示**
線形融雪トレンドの2030年への外挿を「精密な予測ではなくシナリオ」と位置づけるのは妥当だが、この限定はDiscussionだけでなく**Abstract・Results・地図・保全提言にも目立つ形で**置くこと。

### 対応策

**査読者のコード読解は正確だった。** `scripts/sdm/sdm_tdm.R:257-271` を確認したところ:

- 2021年予測: `env_data_21 <- c(terrain, snow_21, sasa_dist_12)` — **2012年分布からの距離**
- 2030年予測: `env_data_30 <- c(terrain, snow_30, sasa_dist_21)` — **2021年分布からの距離**

対応:

1. **Methodsに距離変数の時間的更新規則を明記する。** 「モデルは *t* 時点の分布からの距離を用いて *t+9* 年の分布を予測するよう学習され、2030年投影では観測された2021年分布からの距離を用いた」と書けば、査読者の言う「合理的な動的更新」であることが明確になる。ワークフロー図（Figure 1）にも距離レイヤの更新を図示する。
2. **仮定を明示する。** 上記の定式化は「観測された2021年縁辺からの継続的拡大」を仮定している（予測セルではなく観測セルを起点にしている）。この選択と、逐次的なクローナル拡大をシミュレートしていないことを限界として述べる。
3. **⚠️ 未指摘の不整合を先に直す。** 学習データの距離（`sdm_tdm.R:44-47`）は2012年Sasaピクセル**全体**から計算されているのに対し、予測用の距離（`247-250`）は**5 m²超のポリゴンに限定**してから計算されている。つまり**学習時と予測時で距離変数の定義が異なる**。査読者は気づいていないが、コードが公開されている以上いずれ発見されうる。定義を統一して再計算し、影響を確認すべき。
4. **閾値感度分析**: 0.3 / 0.4 / 0.5 / 0.6 / 0.7 で適地面積・risky域面積がどう変わるかを表にする。あわせて、**訓練データから TSS 最大化閾値（`tss_max`）を求め、それを主たる閾値として採用する**ことを検討。0.5は既定値にすぎないため、キャリブレートされた閾値のほうが正当化しやすい。予測ラスタは保存済みなので再学習不要。
5. **不確実性の可視化**: アンサンブル各メンバー予測のばらつき（SD または分位点範囲）を地図化し、Supporting Information に置く。`model_stack.rds` から算出できる。
6. **TBMの過大予測を正直に扱う。** test TSS = 0.55 は決して高くない。この値を隠さず本文に置き、「TBMは環境適地の上限を示すものであり、実際の分布はそれを大きく下回る。この差が分散制限の存在を示唆する」という**論旨の一部として積極的に利用する**（→ 論点F）。
7. **「シナリオ」表記の徹底**: Abstract・Results・図キャプション・保全提言のそれぞれに、線形外挿に基づくシナリオであることを1文で明記する。図タイトルも "projected" ではなく "scenario" 系の語を使う。

## 7. 論点F: TBM と TDM の比較枠組み

**指摘者: Reviewer 2（Major、Discussion改稿案）**

### 指摘内容

距離を含めたときに予測性能が改善したことは、空間的に制約された拡大と整合的である。しかし**距離は分散制限と未測定の環境構造の両方を表しうる**。さらに、**2つのモデルは異なる応答領域に対して当てはめられているため、性能差を距離変数のみに帰属させることはできない**。環境適性とクローナル拡大の相対的重要性を論じる前に、**共通の評価領域**または明示的な**定着・存続（colonization–persistence）の枠組み**が必要である。

### 対応策

**これは4つの追加解析のうち最も設計変更を要する項目。** 対応の選択肢は2つ。

**選択肢1（推奨・低コスト）: 共通評価領域での再評価**
TBMとTDMを**同一のテストセット**（同じ空間ブロック、同じピクセル集合）で評価し直し、TSS・AUC を並置する。既存の学習済みモデルを使って予測するだけなので、再学習は不要か軽微。これで「異なる応答領域だから比較できない」という批判の大部分は解消する。

**選択肢2（高コスト）: colonization–persistence の明示的枠組み**
応答変数を「2012年に不在→2021年に存在（colonization）」と「2012年に存在→2021年も存在（persistence）」に分解し、それぞれ別モデルを当てる。生態学的には最も正しい定式化だが、応答変数の再定義とモデルの再学習が必要で、日程的に厳しい可能性がある。

**判断**: 28日という期限を考えると、**選択肢1を実施したうえで、選択肢2を「今後の課題」として明記する**のが現実的。ただし選択肢1で性能差が消える場合は、TDMの優位性に関する主張を全面的に見直す必要が生じるため、**この解析は早めに回して結果を確認しておくべき**。

あわせて、**「距離は分散制限と未測定の環境構造の両方を表しうる」という留保を考察に明記する**。Reviewer 2の提案文はほぼそのまま使える。
