## 1. 結論

### 1.1 来歴は確定したか → **確定した。留保は1点のみ**

どの成果物がどのスクリプトから生まれたかは、**ファイル名ではなく保存オブジェクトの内部証拠**
から確定した（§2.1）。留保は 1 点だけである。

- 公表 **TDM**（`models.rds` → `model_stack.rds` → `sasa_pred_tdm_{21,30}.tiff`）は、
  アーカイブされた `sdm_include_distance.R` = リポジトリの `scripts/sdm/sdm_tdm.R`
  （**バイト一致**）から、**無改変で**生成された。再予測が公表ラスタを `maxabs 5.96e-08`
  で再現する。
- 公表 **TBM**（`models_wo_dist.rds` → `model_stack_wo_dist.rds` →
  `sasa_pred_sdm_{21,30}.tiff`）は、`sdm.R` = `scripts/sdm/sdm_tbm.R` の**現在の姿では
  作れない**（現行版は RF 単独で、しかも `models_wo_dist_twi.rds` という存在しない名前に保存する）。
  公表 TBM を作った版は**サーバにも存在しない＝失われている**。
  復元手順（3 ブロックのコメント解除＋保存ファイル名の変更）は**十分に裏づけられた推論**だが、
  証明ではない。応答書ではそう書くこと。

**したがって「公表数値は再現するがパイプラインは再現しない」という以前の総括は、SDM 領域では
もはや正しくない。** 残る非再現要素は (a) 失われた TBM スクリプト本文、(b) `set.seed()` の
位置に起因する在不在間引きの非決定性（§2.7）、の 2 点だけである。

### 1.2 回収資産は何かを買ったか → **3 つのうち 2 つは買った。1 つは買っていない**

### 1.3 ただし、来歴調査の副産物として**中心的主張をより強く脅かす所見が 2 件出た**

F-3 / F-4 / F-5 は元の監査所見だが、今回の作業で出た次の 2 件はそれらより影響が大きい。

**(A) HS > 0.5 は較正された閾値ではなく、既定値である。**
各モデル自身の学習フレーム上で最大 TSS を与える閾値は **TDM 0.1431 / TBM 0.3987**
（自前で厳密に再計算、§3.4）。その閾値で公表ラスタを切り直すと、

```
TDM @0.500 : 2021適地 12,766.04 m2 | 2030新規  4,386.61 | 消失   716.61   ← 公表値
TDM @0.143 : 2021適地 36,190.26 m2 | 2030新規 10,817.11 | 消失     0.00
TBM @0.500 : 2021適地 47,253.26 m2 | 2030新規 27,049.27 | 消失 2,257.77   ← 公表値
TBM @0.396 : 2021適地 85,731.31 m2 | 2030新規 43,344.39 | 消失 1,197.35
観測 2021年ササ = 10,170.45 m2
```

TDM の適地面積は自分自身の較正閾値で**公表値の 2.83 倍・観測の 3.56 倍**になる。
つまり「TBM は 47,253 m² と過大、TDM は 12,766 m² で観測に近い」という論文中心の比較は、
**恣意的な 0.5 という切り方に依存している**。Reviewer 1 主要コメント5 が
"Is 0.5 a calibrated ecological threshold or simply a default probability cut-off?"
と正面から聞いているのはまさにこの点である。

**(B) 同じ 2030年融雪面に対して、2つの公表モデルは逆符号の応答を返す。**

```
TBM 2021 = 47,253.26 → 2030 = 69,176.33   +46.39%   （距離予測子なし＝純粋に融雪駆動）
TDM 2021 = 12,766.04 → 2030（距離を2012に固定）= 12,190.35   −4.51%   （融雪のみ動かした）
```

同一の融雪シナリオが、片方のモデルでは適地を 46% 増やし、もう片方では 4.5% 減らす。
要旨 `index.qmd:53` の "Scenario-based projections under continued snowmelt advance
suggested further expansion of *Sasa* by 2030" と、
`results.qmd:95`（`fig-future-prediction` キャプション）の
"These reductions suggest shifts ... due to earlier snowmelt timing" は、
**フィットされたモデルそのものによって支持されていない**。

**(C) さらに、本統合作業で新たに見つかった定義の不整合が 1 件ある**（§3.5）。
公表の「2030年に不適地化する面積」は、「2030年に新たに適地化する面積」と**別の集合の上で
計算されている**。前者は観測ササポリゴン（>5 m²、計 8,328.46 m²）を分母側の母集団とし、
後者はモデル自身の 2021年適地を母集団とする。両者を並べて「57% が新規適地、21% が不適地化」
と書くことは、1 つの収支の両半分であるかのような誤読を招く。加えて公表の百分率
（21% / 7%）はどちらの分母とも一致しない。

### 2.4 twi の問題 —— 決着

**`twi` はどの公表モデルにも入っていない。** 独立な 4 本の証拠:

1. **レシピの `var_info`**: `models.rds` / `models_wo_dist.rds` / `models_all_5m.rds` のいずれにも
   `twi` は無い（`syn7.R` で `twi present? FALSE` を再確認）。
2. **RF の候補数**（監査が使わなかった指紋）: `tune_grid(grid = 18)` を `mtry = tune()` に
   かけると、提案できる相異なる `mtry` は予測子数までしかない。観測値は **8 / 7 / 6** で、
   `twi` を**含まない**予測子数と厳密に一致する。
3. **公表の変数重要度図**: `vi_tdm.png` はちょうど 8 箱（dist, snow, elevation, aspect, TRI,
   roughness, slope, TPI）、`vi_tbm.png` は 7 箱。
4. **レイヤ順序**: 現在 `data/terrain_features/` を glob すると `twi` が末尾に来るが、
   アーカイブのレシピ順は `… TPI TRI` で終わり `twi` が挿入されていない。

**読み込まれて落とされたのではない。** 学習点で `twi.tif` を抽出すると
平均 **5.708307**、**NA 0 個**（`syn8b.R`）。レイヤは完全に使える。
`sdm.R` に残る死んだ `models_wo_dist_twi.rds` という名前と合わせると、
「公表 → `twi.tif` を追加 → `sdm.R` を RF だけに削って TWI を試す → 公表物を壊さぬよう別名で保存
 → 放棄」という順序になる。

> ただし**「その時点で `twi.tif` がディレクトリに無かった」という物語は証明されていない。**
> 地形 7 ファイルはすべて 2025-12-12 のコピー時刻を持ち、日付では何も決まらない。
> クリーン再実行の行数も、twi 込み（21,397）の方が twi 抜き（21,426）より
> アーカイブ値 21,389 に近い。**事実（どのモデルにも twi は無い）だけを書き、物語は書かないこと。**

#### 利用者判断（未解決判断12「モデルに加える」）を受けた追加検証

`twi` を加えることが共線性の観点で安全かを、公表 TDM の学習点 16,596 で実測した（`syn8b.R`）:

```
twi ~ aspect    r = +0.102     twi ~ TPI    r = -0.462
twi ~ roughness r = -0.285     twi ~ TRI    r = -0.291
twi ~ slope     r = -0.311     twi ~ snow   r = +0.428
twi ~ elevation r = +0.026     twi ~ dist   r = +0.144

|r| > 0.7 のペア（9変数中）:  roughness~slope 0.932 / roughness~TRI 0.970 / slope~TRI 0.943
filter_collinear(cor_caret, 0.7) が残す: roughness, snow, twi, dist, elevation, TPI, aspect
filter_collinear(vif_step,  5  ) が残す: aspect, slope, elevation, TPI, snow, dist, twi
```

- **`twi` は両方のスクリーニングを生き残る。** 最大でも TPI と −0.46 で、追加は安全。
- 真に共線なのは **roughness / slope / TRI の三つ組**（|r| 0.93–0.97）で、提案10の診断を独立に裏づける。
- ただし**2 つのスクリーニングは三つ組のどれを残すかで食い違う**
  （cor_caret は roughness を残し、vif_step は slope を残す）。
  著者自身の `models_all_5m.rds` は `filter_collinear` で roughness と TRI を落として
  slope を残しており、vif_step 側と一致する。**どちらを採るかは§7の判断事項。**

### 2.5 距離変数の問題 —— **バグ修正であって文書修正ではない**

コーパス中に距離の定義が 3 通りある。

| 定義 | 構築場所 | 使用場所 |
|---|---|---|
| **A** 2012年ササ**全画素**からの距離 | `sdm_tdm.R:44-47` | **学習**（L56） |
| **B** 2012 / 2021年ササ**ポリゴン >5 m²** からの距離 | `sdm_tdm.R:247-255` | **予測**（2021年図は 2012年ポリゴン, 2030年図は 2021年ポリゴン） |
| **C** `selected_comms.tiff` からの距離 | `sdm_sasainc.R:40-43`, `analyse_sdm.R:15-18` 等 | ササ増加側の副次解析のみ |

アーカイブ実物との照合（§2.3 の表）:
学習 = **A**（完全一致）、2021年公表図 = **B（2012年ポリゴン）**、2030年公表図 = **B（2021年ポリゴン）**。
**C はどの公表モデルとも一致しない。**

**どのスクリプト版も自己整合していない。** `sdm.R` には距離が無く、
`sdm_include_distance.R` は A と B を同一ファイル内に約 200 行離して持ち、
**上から下へのクリーン実行がこの不整合をそのまま再現する**。
したがってこれは対話実行やワークスペースの残骸の産物ではなく、**コミットされたコードの姿**である。

意図の手がかり: `sdm_tdm.R:36-37` に、学習距離ブロックの直上に
`sasa12_ras %>% terra::as.polygons() %>% filter()` という**代入されない無操作式**がある。
>5 m² 閾値は著者の「本物のササ群落」の標準定義（`select_sasa_communities.R:17`）であり、
公表 HS 図の黒い輪郭にも使われている。**意図はポリゴン基準の一貫適用で、学習側だけが
更新されなかった**と読める。

**→ 応答書には「バグ修正」と書く。** ただし §3.2 のとおり、どちらの直し方も
見出し数値を同じ（不都合な）方向に動かす。

> **利用者判断（未解決判断3 / 提案3）は「学習を予測に合わせる（案B）」**、
> かつ「5 m² フィルタは誤検出パッチからの機械的拡大を抑えるために入れたので、解析全体でこの基準に
> 揃える」。したがって**改訂後の正式な距離定義は B（ポリゴン >5 m²）**となる。
> これは §5.1 の評価に効く（回収資産由来の解析が、改訂後の論文自身の定義の上に載ることになる）。

なお、**2021年図に 2012年距離層、2030年図に 2021年距離層を使う**という設計は
「供給源個体群を前送りする」ものとして妥当だが、**原稿のどこにも書かれていない**。
利用者判断は「妥当だが書いておくべき」。これが F-3 の主題である。

### 3.5 【新規】「2030年に消失」の定義は「新規適地」と非対称である

公表コード `sdm_tdm.R:429-436` の実体:

```r
sasa_pol_21 %>% terra::rasterize(pred_rast_30) %>% rename(sasa_21 = layer) %>%
  c(pred_rast_30) %>%
  filter(sasa_21 == 1) %>%        # 観測された 2021年ササ「ポリゴン >5 m²」
  filter(pred_sasa_30 < 0.5) %>%  # 2030年に不適地と予測
  expanse()
```

- 「新規適地」= **モデル 2021年不適地 → モデル 2030年適地**（モデル対モデル）
- 「消失」= **観測ササポリゴン(>5 m²) → モデル 2030年不適地**（観測対モデル）

**2 つは同じ収支の両半分ではない。** 実測（`syn4.R`）:


## 4. 半ピクセルずれの実影響 —— **化粧ではない。ただし壊滅的でもない**

`fitted_*.tiff` の原点は (0.5, −0.25)、`vege_2012_5x5.tiff` は (0, 0.25)。
原因は `preprocess_snow_data.R:103` の `as_tibble(add_max = TRUE)`。
`sdm_tdm.R:22-28, :265` が既定の**バイリニア** `resample()` をかけるので、ずれは予測子に塗り込まれる。

修正方向は経験的に決定済み: **`terra::shift(dx = +0.5, dy = −0.5)`**
（＝ `as_tibble(add_max = TRUE)` を `as_tibble()` にする）。生の融雪ラスタに対する
相関が 0.972047 → 0.977567、sd(diff) が 6.9275 → 6.2305 に改善し、
かつ有効セル数 1,206,064 が既知の融雪画素数 1,206,063 と一致する。

**予測子への影響**（スクリプト自身の bilinear resample 後）:

| レイヤ | 平均Δ | sdΔ | 最大絶対 | 1 DOY 超のセル |
|---|---|---|---|---|
| fitted_2012 | +0.058 | 1.843 | 68.9 | 30.8% |
| fitted_2021 | +0.045 | 2.162 | 64.2 | 33.2% |
| fitted_2030 | +0.045 | 3.639 | 145.0 | 49.8% |

**公表面積への影響**（両アーカイブスタックで再予測）:

| | 2021年適地 | 2030年新規 | 2030年消失 |
|---|---|---|---|
| TDM, 公表のまま | 12,766.04 | 4,386.61 | 716.61 |
| TDM, 再位置合わせ | 12,844.99（**+0.62%**） | **4,257.68（−2.94%）** | **769.58（+7.39%）** |
| TBM, 公表のまま | 47,253.26 | 27,049.27 | 2,257.77 |
| TBM, 再位置合わせ | 47,281.25（+0.06%） | 27,026.28（−0.08%） | 2,272.76（+0.66%） |

セル単位: `tdm21` で 0.5 をまたぐセル 321（0.08%）、`tbm30` で 10,248（**2.57%**）。

### 判定

**「化粧」という総括は誤りであり、先行報告の要約文は訂正が必要。**

- **6 つの公表面積のうち 2 つが 1% 超動く**: **−2.94%**（4,387 → 4,258 m²）と
  **+7.39%**（717 → 770 m²）。残る 4 つは ≤0.7%。
- **4,387 m² は見出し数値である**（`results.qmd:87` 本文と `fig-future-prediction` キャプション）。
  「消失だけが動く」という言い方は事実に反する。
- **TBM のセル単位地図に対しては化粧ではない**（1.2–2.6% のセルが閾値をまたぐ）。
- **落としてはならない留保**: モデルは**ずれた層で学習されている**
  （保存 `snow` は公表 `fitted_2021.tiff` と maxabs 0 で一致、再位置合わせ層とは 16,596 点中 120 点しか一致しない）。
  上の数値は「フィットしていない予測子にモデルを当てた」ものであり、**効果の大きさの上界を与える**にすぎない。
  完全な修正は `fitted_*` の再生成 → 再学習 → 再予測。
  **「影響は小さいと有界づけた」と書くのは誠実だが、「化粧である」と書くのは不正確。**

### 4.1 さらに、同じ場所に別の非決定性が乗っている（重要）

`verify_assets.md` §3.1 が実測で示したこと（本統合では再実行していないが、検証側の実行ログは明快）:

- **`st_rasterize` は非決定的ではない。** 最後に焼いた点が勝つ決定的仕様で、
  焦点処理前のラスタは公表物と **1,065,641 セル中 0 不一致（100.000000%）**、両年とも。
- **非決定的なのは `terra::focal(3, modal, na.policy="only")` による 140,592 セル（地図の 11.66%）の
  穴埋め**で、`georectify.R` はシードを設定していない。`modal` は同数タイをランダムに割る。
  12 回の独立実行で ササ2012 8,545–8,560 / ササ2021 10,159–10,196 / net +1,603–+1,651 と振れ、
  **公表値（8,547 / 10,176 / +1,629）はすべてこの範囲の内側**にある。
- **同じ穴埋めが融雪ラスタにも掛かっている**（`georectify.R:62-72`、`data/snow/raw/*.tiff`、
  非 NA セル数はすべて 1,206,233 なので同じ 140,592 セル）。
  そこでは**連続値の融雪 DOY** に対して 8 近傍の一様ランダム選択が起きる。
  当該セルの 3×3 近傍の融雪 DOY レンジは中央値 3 日 / 平均 5.5 日 / q90 14 日。
  **これは論文自身の −0.7146 d/yr が 9 年で作る約 6.4 日と同じオーダーであり、
  半ピクセルずれと複合する。**

**含意**: 半ピクセルずれの修正だけを論じるのは片手落ちである。
Zenodo デポジットでは (a) ラスタ実体を同梱するか、(b) `georectify.R` にシードを入れるかの
どちらかが必須。入れないと、スクリプトを再実行した査読者は 8,547 ではなく 8,545–8,560 を得る。

- **これは「99.83% 一致」より強い再現性の言明である**:
  決定的な部分は厳密、確率的な部分は文書化された ±約 10 px の許容内。

#### 先行監査の食い違いの真因（訂正）

`results/*_masked.npy` は **float32 で 0-origin（0–6）**。
しかし先行報告の「1 ずれ + マスク衝突が原因」という説明は**誤り**である
（コード付け替えで比率は変わらない）。実測では 11,779,750 非マスクセルの
**89.34% / 89.38% でしか一致しない** ——
`*_masked.npy` は**別の分類器ヴィンテージ**（公表 200 epoch の重みは失われ、
50 epoch 再実行は 93.8% / 95.4% 一致）。
**「コード体系のずれ」ではなく「別の分類器実行」と書くこと。**

#### Reviewer 3 への含意 — 何をどう言えるか

**Reviewer 3 の指摘**:
> "important information on methodological approaches and specific steps in the analyses
> are not detailed - not ensuring reproducibility of the study."

**言えるようになったこと**: 画像分類 → CSV → 幾何補正 → 公開ラスタの鎖が、
中間成果物つきで端から端まで通った。
以前の「数値は再現するがパイプラインは再現しない」は、
**「分類器の重み以外は完全に再現する。決定的な工程は厳密一致（100.000000%）、
確率的な穴埋め工程のみ ±約10 px の許容がある」**に書き換えられる。

**コスト**: ほぼゼロ（検証済み）。Zenodo に
`results/use_this/{2012,2021}_5x5.npy` と `color2cat.py` を含めるだけ。

**不利に出る道筋（小さいが 2 つある）:**
1. **公開ラスタはビット再現しない**（シードが無い）。査読者が `georectify.R` を再実行すると
   8,547 ではなく 8,545–8,560 を得る。**ラスタ実体を同梱するか、シードを入れるか、どちらか必須。**
2. **ラスタ化は分類済み画素の約 90% を捨てている**（1 m セルあたり平均 11.10 点、中央値 6、
   p90 21、最大 11,707 —— そのうち `georectified.csv` の順序で最後の 1 点だけが残る）。
   多数決に変えると **2012年 4.33% / 2021年 4.35% のセルでクラスが変わり**、
   焦点処理前のササは 8,043 → 7,925、9,622 → 9,554 に動く。
   ただし**純変化はほとんど影響を受けない**（last-point +1,579 vs 多数決 +1,629）。
   1.1% のセルには厳密な多数派が存在しない。
   → 利用者は既に「modal に変更してみよう」と判断済み。**変更しても純変化は動かない見込み**で、
   この予測は上の実測に裏づけられている。

## 7. 判断が必要な事項

ブロックする度合いの順。各項目は一文で答えられる。

1. **HS 閾値を 0.5 のまま維持するか、各モデルの較正閾値（TDM 0.1431 / TBM 0.3987）に変えるか。**
   —— これを決めないと `results.qmd:67, 75, 87, 95` の**すべての面積が確定しない**。

2. **「TDM は観測をよく再現する」という主張を放棄し、「TDM は識別性能で TBM を上回る」に
   置き換えてよいか。** —— 案B でも 14,928 m²（観測の 1.47 倍）、較正閾値ではさらに大きい。
   `results.qmd:67` と `:75` の書き換え文言が決まる。

3. **同一融雪面に対する TBM +46.39% / TDM −4.51% の逆符号を、そのまま開示するか。**
   —— 要旨 `index.qmd:53` と `results.qmd:95` の運命が決まる。開示しない選択肢は実質無い
   （Reviewer 2 は既にコードを読んでいる）。

4. **共線性処理で roughness と slope のどちらを残すか。**
   —— cor_caret は roughness、vif_step は slope、著者自身の `models_all_5m.rds` は slope。
   再学習の予測子セットが確定しない。
